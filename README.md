# Three Harmonics

A daily reading in three frequencies — quotes from the films, books, and scientists who taught me how to keep going, and the deep think that connects them.

**Live:** https://pravinkumar-ghodake.github.io/three-harmonics/

## Format

Each day is one page with three quotes, one theme, and a short first-person reflection after each.

- **Harmonic I** — the anchor
- **Harmonic II** — the counterpoint
- **Harmonic III** — the landing

## Structure 

day-01.html — daily post
index.html — archive + entry point
about.html — the conceit, the author, the sources
style.css — design system
script.js — theme, hero waves, reading progress, fade-in


## Adding a new day

1. Duplicate `day-01.html` → `day-NN.html`
2. Update title, description, canonical URL, JSON-LD `datePublished` and `url`
3. Rewrite the hero, the intro, the three harmonics, the closing
4. Add a `.day-card` entry to `index.html` (a commented example is inline)
5. Add the URL to `sitemap.xml`
